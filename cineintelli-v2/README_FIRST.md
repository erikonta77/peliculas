# CineIntelli V2

## Opción 1 — Uso rápido (recomendado)

Acceder al sistema directamente desde el navegador:

👉 https://cineintelli-production.up.railway.app

Nota:
La primera carga puede tardar unos segundos debido al hosting gratuito.

## Opción 2 — Uso local

Ejecutar:

* Windows: doble clic en start_app.bat
* Linux/Mac:
  ./start_app.sh

Esto abrirá automáticamente la aplicación en el navegador.
